# TREENSE
### What is treense and what does it do?




## INSTALLATION
This guide provides instructions for installing and using the Treense Application Installation Guide

#### Step 1: Download the Application
1. Scan the QR code and download the apk file.

   ![image](https://github.com/user-attachments/assets/6587b739-121a-4408-9ebb-fdb4503d362a)

2. Then click the apk file and click the "Install" button and wait for the installation process to complete.

### How to use the app
1. Open the Treense app and click the "Start Classifying!" button.

   ![image](https://github.com/user-attachments/assets/fc82ea7a-c97a-46fb-bd64-4a71b71ea2c7)

 2. Tap the “Capture Image” button for capturing image.

    ![image](https://github.com/user-attachments/assets/69c45cfa-3c32-4918-89a4-7c02d65c411f)![image](https://github.com/user-attachments/assets/3bfd44ec-3f28-433f-8b81-6f74214d7996)

3.	Alternatively, tap “Upload Image” button to select an existing image from the gallery.

   ![image](https://github.com/user-attachments/assets/b5dc2298-5e9e-4b01-b1c2-7ed946a15d0c)![image](https://github.com/user-attachments/assets/da8969a8-c42e-42da-a794-870374a78caf)
